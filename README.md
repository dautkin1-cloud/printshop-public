# PrintShop

**Локальный менеджер 3D-печати для небольшой мастерской.**
Полностью офлайн, без облака, без регистрации, без телеметрии. Все данные — только на вашем компьютере.

![PrintShop](icon.ico)

---

## О проекте

PrintShop — десктопное приложение для учёта катушек филамента, библиотеки 3D-моделей, заказов клиентов и расчёта стоимости печати. Написано на Python + pywebview, интерфейс — HTML/CSS/JS. Данные хранятся в JSON-файле рядом с приложением, вложенные файлы (STL, 3MF, фото, PDF) — в отдельной папке.

**Аналог Bambu Lab AMS по логике учёта катушек, но с расширенным функционалом.**

---

## Возможности

### 📊 Дашборд
- Сводка по катушкам, проектам, заказам
- Круговая диаграмма остатков по материалам
- Список катушек, требующих замены
- Последние заказы и топ материалов

### 🧵 Катушки
- Учёт: производитель, материал, цвет, диаметр, вес нетто, остаток
- Цена за килограмм и за грамм, авторасчёт стоимости остатка
- Прогресс-бар расхода, предупреждение при остатке < 100 г
- Место хранения, дата покупки, заметки
- 3D-иконка катушки в цвете пластика

### 📦 Проекты (библиотека моделей)
- Grid-карточки с превью 3D-модели
- Встроенный 3D-просмотрщик: **STL, OBJ, 3MF**
- Вращение, зум, авто-поворот модели
- Теги, описание, время печати, вес, базовая цена
- Избранное, счётчик использований
- Вложения: STL, 3MF, G-code, фото, PDF, архивы
- История изменений

### 📋 Заказы (Kanban-доска)
- **6 колонок по статусам: Новый → В печати → Постобработка → Готов → Выдан / Отменён**
- Перетаскивание карточек между колонками (как в amoCRM)
- Данные клиента, контакт, дедлайн, позиции, сумма
- Пользовательские поля
- Вложения с 3D-превью
- История статусов и изменений
- **Автоматический расчёт суммы** из сохранённых калькуляций (округление вверх до 10 ₽)

### 🧮 Калькулятор стоимости печати
- Вес модели, время печати, материал (цена подтягивается из катушек)
- Энергопотребление, тариф, амортизация принтера
- Брак/постобработка, работа оператора, наценка
- Быстрые пресеты: Стандарт / Срочный / Минимум
- Опция «Городская доставка»
- Детальный расчёт себестоимости и итоговой цены
- **Сохранение расчёта в проект или заказ**

### ⚙️ Настройки
- Тарифы, амортизация, символ валюты
- Экспорт/импорт всей базы в JSON
- Пользовательские поля для катушек, проектов и заказов
- Тёмная и светлая темы
